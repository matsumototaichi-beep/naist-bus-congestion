# NAIST バス混雑度 計測アプリ

NAIST（奈良先端科学技術大学院大学）との共同研究で、路線バスの車内混雑度を推定する
**教師データを収集**するためのスマホ向け Web アプリです。調査協力者がバス車内で
混雑度・人数などを回答し、データはクラウド（Supabase）のデータベースに保存されます。

> ⚠️ **このアプリはデータを外部サーバー（Supabase）に送信・保存します。**
> ログインが必要で、回答内容・位置情報・時刻などが記録されます。
> 配布して協力を依頼する際は、下記「収集するデータ」を協力者に必ず説明してください。

## 何をするアプリか

- ログイン後、混雑度を **6 段階のボタンでワンタップ**回答
- 任意で「正確な人数」「乗車バス停」「行先バス停」を追加入力（すべて任意）
- 回答の**時刻**と、可能なら**GPS位置**を自動で付与
- 回答はクラウドDBに送信（オフライン時は端末に退避し、後で自動再送）
- 日本語 / English 切り替え対応

## 収集するデータ（協力者への説明用）

1回の回答ごとに、以下がデータベース（Supabase の `responses` テーブル）に保存されます。

| 項目 | 内容 | 取得 |
|---|---|---|
| congestion_class | 混雑度クラス（1〜6） | 必須（タップ） |
| exact_count | 正確な人数 | 任意 |
| board_stop / dest_stop | 乗車／行先バス停（名前＋座標） | 任意 |
| trajectory | 回答前後のGPS位置（緯度経度・精度・時刻）※取得できた場合 | 自動 |
| answered_at | 回答した端末時刻 | 自動 |
| created_at | サーバー受信時刻 | 自動 |
| surveyor_id | ログインユーザーのID（＝あなたのアカウント） | 自動 |
| display_name | 登録時の表示名 | 登録時 |
| lang, app_version | 言語・アプリ版 | 自動 |

- **位置情報は任意です**。許可しない／取得できない場合は位置なしで送信され、回答は無効にはなりません。
- 回答データは**研究目的**で利用されます。

## 技術構成（実態）

- **認証**：メールアドレス＋パスワードでの登録／ログイン（Supabase Auth）。
  共有の管理者アカウントは、メール形式でない **ID＋パスワード**でもログイン可能。
- **バックエンド**：Supabase（PostgreSQL）。回答は `responses` テーブルへ insert。
  行レベルセキュリティ（RLS）で、各ユーザーは自分の回答のみ insert/参照可能。
- **データ一覧**：管理者アカウントのみ閲覧可能（スタッフには表示されません）。
- **外部依存**：Supabase JS クライアントを CDN（jsDelivr）から読み込み。
  バス停辞書は同梱の `stops.js`。
- **ファイル**：`index.html`（本体）＋ `stops.js`（バス停データ）。ホスティングは GitHub Pages（HTTPS）。

## バス停データの出典

`stops.js` のバス停名・座標は **国土数値情報「バス停留所データ（P11）」（国土交通省）** に基づきます
（奈良県・京都府、平成22年度データ、非商用利用）。

## 使い方（協力者）

1. 上記URLをスマホで開く。
2. メール＋パスワードで登録（またはログイン）。
3. バス車内で混雑度（1〜6）をタップ。必要なら人数・バス停を任意入力して「送信」。
4. 続けて何度でも回答できます。

## セットアップ（開発・運用者向け）

1. Supabase プロジェクトを用意し、`supabase_responses.sql` / `report_feed.sql` を適用。
2. 回答に停留所を含める場合は、`responses` に `board_stop jsonb` / `dest_stop jsonb` を追加。
3. `index.html` 冒頭の `SUPABASE_URL` / `SUPABASE_ANON_KEY`（publishable key）を自分の値に。
4. 管理者は `ADMIN_EMAILS` に、共有管理者IDは同配列と `ID_DOMAIN` の仕組みで設定。
5. GitHub Pages で公開。

## データの扱い・プライバシー

- 回答データはクラウド（Supabase）に保存され、研究チームが分析に利用します。
- 位置情報の取得は任意で、拒否しても回答は送信できます。
- 配布時は、本 README「収集するデータ」の内容を協力者に説明し、同意を得てください。
